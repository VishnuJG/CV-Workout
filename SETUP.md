# Setup Instructions for CV-Workout

## Prerequisites
 before

- Python 3.x
- pip
- Git

## Step-by-Step Setup

1. **Clone the Repository**
   Open your terminal and run:
   ```bash
   git clone https://github.com/VishnuJG/CV-Workout.git
   cd CV-Workout
   ```

2. **Create a Virtual Environment** (optional but recommended)
   ```bash
   python -m venv venv
   source venv/bin/activate  # for Linux/Mac
   .\venv\Scripts\activate  # for Windows
   ```

3. **Install Dependencies**
   Run the following command to install the required packages:
   ```bash
   pip install -r requirements.txt
   ```

4. **Run the Application**
   Start the application by running:
   ```bash
   python app.py
   ```

5. **Access the App**  
   Open a browser and go to `http://localhost:5000` to use the CV-Workout application.

## Troubleshooting
- Ensure you have all necessary dependencies installed.
- If you encounter any errors, please check the repository's issues page or reach out to the contributors.
