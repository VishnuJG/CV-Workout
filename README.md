## Project Overview
CV-Workout is an innovative application that utilizes computer vision techniques to enhance workout routines. The application provides users with a unique way to monitor their exercises through video analysis.

## Technologies Used
- Python
- OpenCV
- Flask (for web development)
- HTML/CSS/JavaScript (for frontend)

## Installation Instructions
To get started with CV-Workout, follow these steps:
1. Clone the repository:
   ```bash
   git clone https://github.com/VishnuJG/CV-Workout.git
   ```
2. Install the required packages:
   ```bash
   pip install -r requirements.txt
   ```

## How to Use
1. Run the application:
   ```bash
   python app.py
   ```
2. Navigate to `http://localhost:5000` on your browser.
